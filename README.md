## Overview

CampusOS is a student-centric mobile application
designed to simplify campus life through a unified
and intuitive digital platform.

Built using React Native, Expo and TypeScript,
CampusOS focuses on modern user experiences,
modular architecture and maintainable mobile
application development.

## Project Objectives

- Simplify access to digital campus services.
- Deliver a modern mobile user experience.
- Build reusable and maintainable UI components.
- Support cross-platform mobile development.
- Establish a foundation for future campus integrations.

## Key Features

- Modern student-focused mobile interface.
- File-based navigation using Expo Router.
- Reusable UI components.
- Interactive campus transport map.
- Demonstration bus locations and route information.
- NativeWind and Tailwind CSS styling.
- Android build configuration using EAS.

## Getting Started

### Prerequisites

- Node.js
- npm
- Android Studio or a physical Android device
- Android development tools for native builds

### Installation

Clone the repository:

```bash
git clone https://github.com/vinodDeveloper440/campusos.git
cd campusos
```

Install dependencies:

```bash
npm ci
```

Start the development server:

```bash
npm start
```

Build and run on Android:

```bash
npm run android
```

Run on the web:

```bash
npm run web
```

Check code quality:

```bash
npm run lint
```
