# CampusOS

CampusOS is a student-focused mobile app built with Expo, React Native, and Expo Router.

## Get started

1. Install Node.js and npm.
2. From this folder, run npm ci to install the locked dependencies.
3. Run npm start to launch the Expo development server.

Use the Expo CLI prompts to open the app on a device or emulator. Run npm run web for the web target, or npm run android and npm run ios for native builds.

The campus transport map uses MapLibre on Android and iOS. Bus locations and route data in this screen are demo values; live tracking requires a GPS/backend connection.

## Project layout

- src/app/ — Expo Router screens and layouts
- src/components/ — reusable interface components
- src/constants/, src/data/, src/hooks/ — shared app code
- assets/ — images, icons, and models
- android/ — Android native project files
